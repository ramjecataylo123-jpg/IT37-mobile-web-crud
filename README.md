# IT37 Mobile-Web Integration CRUD Project

## How to Run
1. **Backend (Node.js + Express):**
   - Open `backend` folder
   - Run `npm install`
   - Run `node server.js`

2. **Mobile App (React Native + Expo):**
   - Open `mobile` folder
   - Update `API_URL` in `src/app/index.tsx` to your PC's local IPv4 address (example: `http://192.168.8.35:3000/api/items`)
   - Run `npm install`
   - Run `npx expo start` and open in Expo Go
